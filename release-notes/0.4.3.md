# 0.4.3

## Added

- Sync local SVG images as PNG while keeping the source files, note references, captions, and display sizes. SVGs are included in image galleries, sync-ignore trees, and media change detection. Rendered images are cached by source content, with size limits for large SVGs. Obsidian uses its built-in browser; Git hooks require `resvg` on `PATH` (`brew install resvg` on macOS). Embed external images in the SVG first, and export SVGs containing scripts or HTML as plain SVG or PNG.

## Fixed

- Read display sizes from Markdown image captions such as `![Architecture|600](diagram.png)` and `![Architecture|600x400](diagram.png)`. Size suffixes are removed from captions, width-only sizes preserve the aspect ratio, and both Markdown and Wiki images accept `×` between dimensions.
- Removing a folder's saved link now also removes links for its subfolders, notes, and PDFs, together with pending bindings and incremental-sync state. Old frontmatter cannot restore the removed links. An upgrade also clears descendant records left behind by earlier folder removals. Local files and Feishu/Lark files are kept.
- Avoid a false “remote update is not yet visible” error after image uploads when the remote XML body repeats the document title as its first heading. Other body differences still fail verification, and block mappings stay aligned with the body.
- Validate native-export block responses, image mappings, and rich-text structures before using them, and stop sync when a response is invalid.

Requires Obsidian 1.13.0 or later on desktop.
